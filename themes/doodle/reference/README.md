# InstaHelp homepage reference

`instahelp-index-doodle.html` is a snapshot of the InstaHelp homepage **with doodle theme enabled**.

It is **not** standalone - it expects these files from the InstaHelp repo root:

- `style.css` - main site layout
- `main.js` - form behaviour

And from this doodle package:

- `../css/doodle.css`
- `../js/doodle.js`

Use it as **HTML/markup reference** when re-applying the doodle design to `index.html`.

For a standalone preview that needs nothing else, open **`../example.html`** instead.
